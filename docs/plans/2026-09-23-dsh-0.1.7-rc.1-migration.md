## 升级卡摘要（仅保留命中 ∩ face 的卡）

| 卡 | 类型 | 内容 | 级别 | 命中 |
|---|---|---|---|---|
| RC1-01 | breaking | 全部 `@deepseek-ai/dsh-*` peer + dev 提到 `^0.1.7-rc.1`（DSH 在安装与启动强制 peer 兼容，`>=0.1.5-rc.1` 这类 prerelease 下界**不**放行 `0.1.7-rc.1`） | required-if-hit | ✅ |

| RC1-02 | breaking | PTC 运行时改名（`codeRuntime`→`ptcRuntime`，`dsh-code-runtime`→`dsh-ptc-runtime`） | required | ❌ 非命中（见下） |

## 触点分析（7 类扫描，排除 node_modules/lib/docs）

| 触点 | 命中 | 证据 |
|---|---:|---|
| #1 patch / 依赖 | ✅ | 4 个 package.json 的 `@deepseek-ai/dsh-*` peer/dev 版本；lockfile 旧 cohort |
| #2 events | ❌ | 源码无 `SessionEvent`/`ctx.on(` 生产订阅（测试用 loader 组合除外） |
| #3 services/Remote | ❌ | 无 `codeRuntime`/`CodeRuntime`/`CodeSdkLanguage`/`ctx.codeRuntime`；服务面只用 `ctx.codegraph`（自有 seam） |
| #4 filesystem | ❌ | 无 `.dsh/`/profiles 直读写（tree-sitter 只读工作区 `.codegraph/`） |
| #5 UI/commands/tools | ❌ | Host-only；`defineTool` 名称/签名 rc.1 未变 |
| #6 custom channel | ❌ | 无 HTTP/WS/Router |
| #7 subprocess/output | ❌ | 无 `dsh-code-runtime`/`workflow-worker-thread` 引用；tree-sitter worker 用 `node:worker_threads` 自管 |

**RC1-02 非命中证据**：`rg -n 'codeRuntime|CodeRuntime|CodeSdkLanguage|code-runtime|workflow-worker-thread'` 在 `packages/**` 源码 0 命中；lockfile 曾出现 `@deepseek-ai/dsh-code-runtime@0.1.0-rc.8`，那是 `dsh-tools@0.1.5-rc.1` 的**传递依赖**，不是本仓引用。rc.1 重装后该依赖变为 `@deepseek-ai/dsh-ptc-runtime@0.1.7-rc.1`。

## 改动

1. **RC1-01** — `pnpm install` 前把这些文件的旧范围改为 `^0.1.7-rc.1`：
   - `package.json`（root）：`dsh-agent` / `dsh-fs-local` / `dsh-session`（原精确 `0.1.5-rc.1`）
   - `packages/service/package.json`：`dsh-brand`（原 `>=0.1.0-rc.6`）/ `dsh-llm`
   - `packages/sqlite/package.json`：`dsh-llm` / `dsh-util-values`
   - `packages/tool/package.json`：`dsh-fs` / `dsh-llm` / `dsh-system-prompt` / `dsh-timeout`（原 `>=0.1.0-rc.6`）/ `dsh-tools` / `dsh-util-values`
   - `@deepseek-ai/cordis`、`@deepseek-ai/schemastery` 保持原样。
2. **RC1-16** — `pnpm install` 重生 `pnpm-lock.yaml`：旧 cohort（`dsh-code-runtime@0.1.0-rc.8`、`dsh-sandbox@0.1.0-rc.8`、`dsh-scope@0.1.0-rc.8`、`dsh-user-approval@0.1.0-rc.8`、`dsh-invariants@0.1.2-alpha.2`、`dsh-session-projection@0.1.2-alpha.2`）全部清零。`pnpm-workspace.yaml` 的 40 行旧 `minimumReleaseAgeExclude` 一并清理。

无源码改动。
