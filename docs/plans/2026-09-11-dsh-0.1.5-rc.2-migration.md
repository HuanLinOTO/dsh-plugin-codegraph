- **RC2-01/02/05 · 非命中**：全仓 rg 无 `dsh-client-ui-message-feedback`、feedback 注入契约、分类文案引用。
- **RC2-03 · 非命中**：client 面不渲染 `FileTypeIcon`，无图标快照断言。
- **RC2-04 · 非命中**：不贡献 `conversation.chat.turnTail`。
- **RC2-06 · 关键**：tool / service / sqlite / tree-sitter 均为 Host 面包，本 edge Host 面零行为变更 → 结构性免疫；
  bundle 的 client 面亦无触点。
